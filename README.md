# standard-model
Immutable dataclass representation of Standard Model particle properties, physical constants, and rest-energy/mass unit conversion utilities. Intended to serve as a reusable data structure for scientific computation and an educational tool for exploring particle mass-energy relationships.

The Python script establishes a structured reference for the Standard Model of particle physics by defining immutable dataclasses that encapsulate fundamental constants like the speed of light and the Planck constant, and detailed attributes for quarks, leptons, gauge bosons including rest masses, electric charges, and spin values.

Each particle object provides utility methods to compute rest energy in joules, electron-volts, or mega-electron-volts, as well as mass conversions to atomic mass units, leveraging precise SI conversion factors. The script populates a comprehensive dictionary of known particles from the up quark to the Higgs boson and hypothetical graviton and supports direct execution to print all properties and calculated physical values.
